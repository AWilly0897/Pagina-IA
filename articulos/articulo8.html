Artículo 8 — APIs y seguridad mínima

Qué es una API, cómo consumirla y reglas básicas para no exponer secretos.

Conceptos

API = interfaz para que aplicaciones se comuniquen. Usá HTTPS, no incluyas tokens en el frontend y validá entradas en el backend.

Ejemplo práctico

En este proyecto el envío opcional de comentarios apunta a /api/nuevo-comentario. Si implementás ese endpoint, guardá secretos en variables de entorno y validá datos.

Laboratorio

Simulá una respuesta de API con fetch a un JSON local (archivo en public/) y maneja el resultado en la UI.
