Artículo 5 — Servidores y por qué no usar file://

Explicación práctica de HTTP, orígenes y por qué muchas funciones (fetch, módulos) requieren un servidor.

Por qué usar un servidor local

El navegador trata los archivos locales como orígenes distintos y bloquea ciertas operaciones por seguridad. Un servidor local simula el entorno real y evita errores como Failed to fetch.

Cómo levantar un servidor

  • Python 3: python -m http.server 8000
  • Node: npx http-server . -p 8000
  • VS Code: extensión Live Server

Laboratorio

Levanta el servidor y abre http://localhost:8000/articulos/articulo5.html. En Network verifica que componentes/formulario-comentario.html y componentes/footer.html devuelvan 200.

Ejercicio sugerido

Prueba abrir el archivo con file:// y observa la consola; luego levanta el servidor y compara el comportamiento.
