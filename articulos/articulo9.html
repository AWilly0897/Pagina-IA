Artículo 9 — Flujo completo: local → remoto → deploy

Pasos para pasar de tu máquina al sitio público sin romper la experiencia de los usuarios.

Pasos resumidos

  1. Probar localmente con servidor HTTP.
  2. Commit y push a GitHub.
  3. Configurar deploy en Vercel o GitHub Pages.
  4. Verificar logs de build y probar la URL pública.

Laboratorio

Hacé un cambio pequeño (texto o estilo), commitealo y pushealo; luego verificá que el deploy se actualice y que la página pública muestre el cambio.
