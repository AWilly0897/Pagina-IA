Artículo 4 — JavaScript: comportamiento y lógica

Cómo JavaScript conecta la interfaz con la lógica: eventos, DOM y fetch.

Qué aprenderás

Entenderás cómo reaccionar a acciones del usuario (clicks, envíos), cómo manipular el DOM y cómo manejar peticiones a APIs con fetch. También verás buenas prácticas para evitar errores comunes.

Conceptos clave

  • Eventos: escuchar y responder (ej. submit, click).
  • DOM: seleccionar nodos, crear y actualizar contenido.
  • Asincronía: promesas, async/await y manejo de errores.
  • Validación: comprobar entradas antes de procesarlas.

Ejemplo práctico

En este proyecto el archivo js/comentario.js gestiona el envío del formulario, guarda en localStorage y renderiza los comentarios. Abrí DevTools → Console para ver errores y Network para ver peticiones.

Laboratorio

  1. Abre la página y envía un comentario desde el formulario.
  2. En DevTools → Console busca mensajes de error o advertencia.
  3. En DevTools → Application → Local Storage revisa la clave comentariosPublicados.
  4. Modifica temporalmente js/comentario.js para añadir un console.log y recarga para ver el flujo.

Ejercicio sugerido

Agregá una validación que impida enviar comentarios con menos de 10 caracteres y muestre un mensaje amigable al usuario.
