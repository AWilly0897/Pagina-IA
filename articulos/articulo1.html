Qué es este proyecto, por qué la IA ayuda y por qué las bases técnicas son necesarias.

Ir al Artículo 2

Resumen

Este proyecto, Pensamiento-Abierto-Tercera-Edición, es una guía práctica y un laboratorio mínimo para que cualquier persona pueda entender cómo la IA puede ayudar en tareas web, y qué conocimientos básicos son imprescindibles para trabajar con ella.

Estructura del proyecto

  • index.html — índice con enlaces a los artículos.
  • articulos/ — páginas individuales con data-articulo-id
  • componentes/ — formulario-comentario.html y footer.html.
  • css/ — estilos globales y del formulario.
  • js/ — scripts para cargar componentes y manejar comentarios.

Laboratorio

Probá el formulario de comentarios abajo. Si abrís el proyecto localmente, usá un servidor HTTP (no abrir con doble clic).

Comentarios

    Cómo probar localmente

    1. Abrí la terminal en la raíz del proyecto.
    2. Ejecutá python -m http.server 8000 o npx http-server . -p 8000.
    3. Abrí http://localhost:8000/articulos/articulo1.html en el navegador.
    4. DevTools → Network: verificar que componentes/formulario-comentario.html y componentes/footer.html devuelvan 200.

    Ejercicios prácticos

    Ejercicio guiado

    1. Abre el proyecto en tu editor de código.
    2. Verifica que la carpeta articulos/ contiene articulo1.html.
    3. Agrega un nuevo archivo articulo-test.html dentro de articulos/.
    4. En index.html, enlaza este nuevo archivo y comprueba que el enlace funciona.

    Objetivo: entender cómo se conectan las rutas y comprobar que la estructura es reproducible.

    Ejercicio libre

    Crea una carpeta llamada imagenes/ y coloca dentro una imagen de prueba. Luego enlázala desde articulo1.html usando la etiqueta <img>. Verifica en DevTools → Network que la imagen se carga correctamente (status 200).

    Objetivo: practicar la organización de recursos y validar rutas relativas.

    Checklist final

    • ✔ El proyecto se abre en un servidor local.
    • ✔ Los enlaces entre artículos funcionan.
    • ✔ Los componentes se cargan con status 200.
    • ✔ La imagen de prueba aparece correctamente.
