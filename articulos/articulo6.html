Artículo 6 — Git básico: versionar sin miedo

Comandos esenciales para mantener tu trabajo seguro y colaborar sin romper producción.

Comandos mínimos

  • git init — iniciar repo
  • git status — ver cambios
  • git add . — preparar cambios
  • git commit -m "mensaje" — guardar snapshot
  • git push origin main — subir al remoto
  • git checkout -b rama-nueva — crear rama

Buenas prácticas

  1. Hacer commits pequeños y descriptivos.
  2. Crear ramas para features o correcciones.
  3. Hacer backup antes de cambios grandes (crear rama de respaldo).

Laboratorio

En la raíz del proyecto ejecutá los comandos para crear una rama de respaldo y pusheala al remoto (si tenés remoto configurado).
